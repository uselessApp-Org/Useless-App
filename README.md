## Setting up the Environment
1. Ensure you have .Net 9.0 installed
....* 'dotnet --version'
2. Ensure you have the required NuGet Dependencies
....* 'dotnet restore'
3. Build the project
....* `dotnet build`
4. Run the project
....* `dotnet run`
5. This enables live updates to you just save to see updates
....* 'dotnet watch'
